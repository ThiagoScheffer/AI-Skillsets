# Product Design / UX

Define how users accomplish the required outcomes. Do not conflate interaction design with visual branding or implementation CSS.

## Capture

- primary journeys
- information architecture
- navigation model
- state transitions
- loading/empty/error states
- permissions and denied states
- destructive action confirmation/recovery
- form validation behavior
- responsive behavior
- keyboard/focus expectations
- accessibility-sensitive interactions

## Evidence

Link critical journeys to requirement and acceptance-criteria IDs.

For substantial workflows, use text-based flow/state diagrams where they improve clarity.
