# Product Requirements Document

Status: Approved for example purposes

## Problem
Users need a consolidated view of selected technology events.

## Objective
Provide a searchable event catalogue with reliable source attribution.

## In scope
- ingest selected public event metadata
- show event cards
- preserve source links

## Out of scope
- ticket purchase processing
- organizer CRM

## Success
Defined during real project discovery; this sample intentionally omits invented metrics.
