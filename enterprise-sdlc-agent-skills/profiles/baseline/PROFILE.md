# Baseline Engineering Profile

Applies to all projects unless explicitly replaced by a stricter requirement.

## Expected principles

- least privilege
- secure defaults
- explicit trust boundaries
- validated external inputs
- secrets kept out of source control
- dependency provenance and patching awareness
- meaningful logging without sensitive-data leakage
- explicit rollback/recovery strategy for material releases
- accessibility considered for user-facing systems
- requirement-to-verification traceability for material behavior

This profile is an engineering baseline, not a compliance certification.
