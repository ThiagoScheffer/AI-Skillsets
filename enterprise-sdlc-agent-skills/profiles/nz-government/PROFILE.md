# New Zealand Government Profile

Use for New Zealand public-sector systems or when a project explicitly adopts NZ government security/accessibility requirements.

## Overlay

In addition to baseline/NZ privacy considerations, assess:
- applicable NZISM controls and agency-specific security policy
- information classification and handling
- identity/access assurance
- privileged administration
- vulnerability/change management
- security logging and monitoring
- supply-chain/cloud/service-provider considerations
- incident and recovery requirements
- government web accessibility obligations

For mandated NZ government web pages, plan against the applicable current NZ Government Web Accessibility Standard and WCAG requirements selected by the project authority.

## Human gates

R3 should normally be assumed unless project authority documents otherwise. Architecture, security/privacy and production-release gates should be explicit.

This profile does not certify NZISM conformance. Maintain a project-specific control mapping where conformance is required.
