# New Zealand Private-Sector Profile

Use for applications operating in New Zealand or processing personal information in a context where New Zealand privacy obligations are relevant.

## Design prompts

Evaluate:
- purpose and necessity of collection
- direct vs indirect collection
- notice/transparency obligations
- storage/security safeguards
- access/correction capability
- retention/deletion
- disclosure and offshore disclosure
- identifiers and minimisation
- incident/breach handling

## IPP 3A awareness

For personal information collected indirectly, explicitly assess whether the project requires notification to the individual and whether an exception applies. Record this in the privacy assessment rather than assuming indirect collection is transparent.
