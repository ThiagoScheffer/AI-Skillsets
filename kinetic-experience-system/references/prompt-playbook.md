# Prompt playbook (copy examples and adapt)

## Existing React store

> Use kx-orchestrator in RETROFIT mode. Inspect existing React Router version and navigation/scroll state. Design a semantic shared-element transition for catalog tile to product detail, preserving SEO, keyboard, browser Back, loading states, analytics and component tests. Implement one route pair as a reversible patch, generate a validated Motion Blueprint, and show test evidence.

## New creative studio website

> Use kx-orchestrator in GREENFIELD mode. Define audience, pages, content strategy and a motion grammar before choosing technology. Propose 3 materially different navigation models (continuity, spatial, editorial); choose based on value, accessibility, feasibility and performance. Build a cohesive site with one signature transition, quiet utility interactions and responsive reduced-motion experience.

## Existing dashboard

> Use kx-microinteractions in FOCUSED mode. Improve tab/filter/change-state feedback without delaying workflow, replacing the router or increasing global animation dependencies unnecessarily. Preserve focus and accessibility; measure actual interaction latency if tooling permits.

## Advanced reference-based exploration

> Study the conceptual choreography behind Codrops Amber/Hyperkinetic, but do not copy its art direction or assume the alpha engine is production-ready. Create a different original interaction model. Verify router compatibility and clearly separate live parallel DOM transitions from snapshot View Transitions.

## Review-only

> Use kx-experience-audit and kx-visual-qa to analyze the site without changing code. Produce ranked opportunities, implementation risks, design judgments and an explicit list of untested items.
