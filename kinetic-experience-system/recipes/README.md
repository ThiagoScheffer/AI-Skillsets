# KX recipe index

These are educational source patterns, **not a published SDK** or verified drop-in components. Adapt them to each project's router version, types, styling, focus lifecycle and browser test infrastructure.

| Recipe | Primary technique | Use |
|---|---|---|
| `native-view-transition` | React Router + snapshots | Route continuity without live outgoing DOM |
| `motion-shared-layout` | Motion layoutId / AnimatePresence | React layout identity transitions |
| `gsap-choreography` | GSAP + scoped useGSAP | Multi-element timed entrances and exits |
| `parallel-navigation` | Hyperkinetic alpha evaluation | True live concurrent React Router pages |
| `typography-reveal` | Accessible CSS typography | Light kinetic editorial type |
| `spatial-persistence` | Persistent R3F scene blueprint | Spatial camera/object continuity |
| `microinteraction` | Motion + semantic controls | Tab indicator and localized state |
| `vanilla-flip` | WAAPI + visual proxy | Framework-agnostic geometry morph |

## Before copying code

1. Define the semantic relationship and fallback using a valid Motion Blueprint.
2. Verify vendor APIs and dependencies against current installed versions.
3. Assign transform/opacity ownership per DOM wrapper.
4. Add focus/history/scroll/error handling to the host app.
5. Test reduced motion, direct links, rapid navigation and performance.
