# Future development plan (not implemented in v1.0)

## v1.1 — Evidence and evaluation

- Automated agent-eval harness that checks whether skills activate for correct tasks and do not over-engineer routine work.
- Playwright sample app and repeatable transition trace/video captures with a browser-based visual review procedure.
- AST-based motion property ownership linting for React/CSS code, with conservative false-positive management.
- Full JSON Schema validator integration as an optional development dependency.

## v1.2 — Framework integrations

- Tested Next.js client-boundary snapshot/shared-element adapter for a specified Next version.
- Vue/Nuxt reference implementation, not just adapter guidance.
- Native View Transition name registry with route-scoped identity and interruption protection.

## v1.3 — Motion tooling

- Animation timeline instrumentation and capture/replay in development.
- Automatic route-seam suggestion report based on AST/JSX semantics and app journeys.
- Motion intensity presets compiled into site-wide tokens and user preferences.

## v2.x — Spatial and creative evaluation

- Instrumented WebGL reference build with context-loss fallback and adaptive quality.
- Three-direction prototyping workflow and human-in-loop design comparison.
- Frame-series comparison and accessibility/visual regression CI.

**Guardrail:** no roadmap item should mandate new runtime dependencies for projects that do not need them. All upgrades need empirical evaluation against current sample apps.
